# 库存监控工具

监控网页库存状态，到货自动通知。

## 使用方法

### 1. 编辑配置文件

打开 `config.json`，添加你要监控的商品：

```json
{
    "interval": 30,
    "items": [
        {
            "name": "商品名称",
            "url": "商品页面地址",
            "in_stock_keywords": ["有货", "加入购物车", "立即购买"],
            "out_of_stock_keywords": ["缺货", "售罄", "无货"],
            "enabled": true
        }
    ]
}
```

### 2. 运行监控

```bash
python monitor.py
```

### 3. 停止监控

按 `Ctrl+C` 停止

## 配置说明

| 字段 | 说明 |
|------|------|
| `interval` | 检查间隔，单位秒，默认30 |
| `name` | 商品名称，用于通知显示 |
| `url` | 要监控的页面地址 |
| `in_stock_keywords` | 有货时页面中出现的关键词 |
| `out_of_stock_keywords` | 缺货时页面中出现的关键词 |
| `enabled` | 是否启用此监控项 |

## 注意事项

- 本工具只做页面关键词检测，不模拟任何操作
- 部分网站需要登录才能看到库存状态，本工具无法处理
- 建议设置合理的检查间隔（30秒以上），避免被封IP
- 本工具仅供学习和个人使用

## 日志

监控日志保存在 `monitor.log` 文件中
